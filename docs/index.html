小红书下载助手 · 隐私政策

最后更新：2026-08-22 · 版本 1.0.0 · 常见问题

本扩展（「小红书下载助手」）由个人开发者提供。我们重视您的隐私。本政策说明本扩展如何处理信息。

1. 我们收集哪些数据

我们不收集、不存储、不上传、不出售任何个人数据。

  • 不收集姓名、邮箱、账号密码
  • 不收集浏览历史并发送到第三方服务器
  • 不使用分析/追踪 SDK
  • 不含第三方广告网络；可能展示开发者公告与合作说明（静态 JSON 文本）

2. 本地处理说明

本扩展仅在您访问 xiaohongshu.com 相关页面时运行。识别与保存都在您的浏览器本地完成。下载文件保存到您设备上的浏览器默认下载目录。

扩展读取详情页媒体或您选中的笔记页面，不绕过登录、付费或私密限制。

3. 权限用途

  • activeTab：识别当前笔记或主页
  • downloads：通过浏览器下载管理器保存您主动请求的文件
  • storage：本地保存设置、媒体缓存和下载记录
  • xiaohongshu.com / xhscdn.com：读取页面、选中笔记与媒体并下载
  • download-config-hub：读取公开的公告、合作说明与评分开关 JSON

4. 远程代码

本扩展为 Manifest V3，不加载、不执行任何远程托管代码。所有脚本均包含在扩展安装包内。扩展可能请求配置站静态 JSON，仅用于展示公告、开发合作与评分开关。

5. 数据共享

我们不会与第三方共享用户数据，因为我们不收集用户数据。

6. 合规使用

本扩展仅供个人学习与研究。请仅保存你有权保存、且页面中已经能正常查看的公开内容。请勿用于侵犯版权、绕过登录/付费/私密限制，或违反小红书用户协议的行为。用户应自行对保存与使用内容负责。

7. 政策变更

若本政策更新，将在本页面修改「最后更新」日期。

8. 联系我们

如有隐私相关问题，请发邮件至 hangdudu0@agent.qq.com 联系开发者。
